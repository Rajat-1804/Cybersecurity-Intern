# Cybersecurity and Ethical Hacking Internship - Task 1

## Foundation & Environment Setup

### Overview

This repository contains the work completed for Task 1 of the Cybersecurity and Ethical Hacking Internship. The objective of this task was to build a cybersecurity lab environment, learn Linux fundamentals, understand networking and cryptography concepts, and become familiar with essential cybersecurity tools.

---

## Objectives

* Understand cybersecurity fundamentals.
* Learn the CIA Triad (Confidentiality, Integrity, Availability).
* Set up a virtual lab environment using VMware.
* Install and configure Kali Linux and Metasploitable2.
* Learn Linux commands and file permissions.
* Understand networking concepts and protocols.
* Explore cryptography fundamentals.
* Gain hands-on experience with cybersecurity tools.
